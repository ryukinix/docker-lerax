# How can I use it?

```bash
docker run -it ryukinix/lerax
```

# Dev

Build image locally

```
make build
```

Publish image

```
make publish
```

Publish image with texlive-full (ryukinix/lerax:tex)

```
make publish-tex
```

Warning: image with size of 9GB.
